# ASSESSMENT_UI_CONTRACT — V1

- Mount and payload: `#assessment-app` with `data-session-id`, `data-complete-url`, `data-save-base-url`, `data-session-url`; `#assessment-initial-data` contains the session payload. The JS sorts questions by position and resumes from `progress.current_position`.
- Question and progress: `#scenario-text`, `#scenario-badge`, `#badge-num`, `#current-position-num`, `#total-questions-num`, `#processed-count-num`, `#progress-bar-container`, `#progress-bar-fill`, `#options-container` and `#questions-nav-grid` are accessed by JS.
- Answers: each of the four `question.options` has `option_id` and `option_text`. One `primary_option_id` is chosen using `name=primary_option`. Once chosen, each of the four options shows its own optional five-level rating, including the selected primary option. An active rating may be cleared by choosing it again. Preserve numeric mapping and labels; display the approved emoji package order `-2,-1,0,+1,+2`.
- Special responses: `#none-fit-radio`, `#none-fit-card`, `#cannot-judge-radio`, `#cannot-judge-card`, `name=response_state` and their values are required. Selecting either clears primary and ratings. Their distinct meanings must remain.
- Save: `#save-status-icon`, `#save-status-text`, `#error-alert`, `#error-alert-message`, `#retry-save-btn` support pending/confirmed/error UI. The 350 ms debounce, PUT payload `{primary_option_id, none_selected, unable_to_judge, ratings:[{option_id,rating}]}`, CSRF header, abort handling and server acknowledgement determine save state.
- Navigation and completion: `#prev-btn`, `#next-btn`, `#complete-btn`; `#conflict-modal`, `#conflict-keep-btn`, `#conflict-review-btn`; `#completion-modal`, `#completion-confirm-btn`, `#completion-cancel-btn`, `#completion-modal-error` are JS dependencies. Negative ratings on a primary option require conflict confirmation. Completion remains server controlled.
- Constraints: do not change scoring, routes, payload, answer semantics, save or completion flow. On smaller phones the page scrolls naturally; avoid internal scroll areas that conceal the two special responses or navigation.
