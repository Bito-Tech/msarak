# تجهيز دليل التخصصات — مسارك

## الهدف
هذه الوثيقة تثبت تجهيز صفحة **دليل التخصصات** قبل إعادة تصميمها، بحيث تعتمد على مصدر البيانات الحالي ولا تكرر المحتوى أو تغير عقود المقارنة.

## مصدر المحتوى
المصدر الوحيد للنصوص العلمية هو:
`resources/data/specializations.json`

عدد التخصصات المعتمد: **10**.

لا تُنشأ أوصاف علمية جديدة داخل Blade. كل بطاقة تقرأ محتواها من JSON الحالي.

## ترتيب التخصصات
1. علوم الحاسوب وتقنية المعلومات
2. الطب البشري
3. التمريض
4. الهندسة المدنية
5. الهندسة المعمارية
6. إدارة الأعمال
7. المحاسبة
8. الحقوق والقانون
9. التصميم الجرافيكي والوسائط المتعددة
10. اللغة الإنجليزية والترجمة

## تنظيم بطاقة التخصص في الدليل
كل بطاقة تعرض فقط:
- الصورة المعتمدة إن كانت نسخة إنتاجية مسموحة.
- اسم التخصص.
- الوصف الأساسي من `description`.
- شارة قصيرة مأخوذة من طبيعة الدراسة عند الحاجة، دون تغيير المعنى.
- زر كبير: **عرض التفاصيل**.
- زر ثانٍ: **أضف للمقارنة**.

لا نعرض كل `key_activities` و`required_skills` و`career_paths` داخل صفحة الدليل حتى لا تتحول البطاقة إلى صفحة تفاصيل.

## تنظيم صفحة تفاصيل كل تخصص لاحقًا
الترتيب الثابت:
1. Hero: الصورة + اسم التخصص + الوصف.
2. طبيعة الدراسة — `study_nature`.
3. أبرز الأنشطة — `key_activities`.
4. المهارات المطلوبة — `required_skills`.
5. المسارات الوظيفية — `career_paths`.
6. المصادر — `sources`.
7. زر المقارنة.

### سياسة الأصول
- الصور المجانية الست من Unsplash صالحة للإنتاج بعد تنزيل النسخة الأصلية.
- التمريض يحتاج نسخة iStock مرخصة.
- المحاسبة والقانون يحتاجان ترخيص Unsplash+.
- مرجع الإنجليزية الحالي بعلامة iStock المائية **مرجع فقط** ولا يوضع في واجهة الإنتاج.
- عند غياب أصل مرخص، نستخدم أيقونة التخصص الحالية كـfallback ولا نخترع صورة بديلة ولا نزيل علامة مائية.

## هوية التصميم المعتمدة
- الخلفية العامة: mineral / teal فاتح مثل الصفحات المعتمدة.
- اللون الرئيسي: Teal.
- Accent: ذهبي هادئ.
- الخط: IBM Plex Sans Arabic الموجود في المشروع.
- الصور باهتة قليلًا داخل البطاقات حتى يبقى النص واضحًا.
- الأزرار كبيرة وواضحة.
- الهاتف: بطاقة عمودية، صورة أعلى البطاقة، الأزرار بعرض كامل.
- الكمبيوتر: شبكة واسعة تستغل عرض الشاشة، مع المحافظة على قابلية القراءة.

## معايير القبول قبل اعتماد صفحة الدليل
- التخصصات العشرة ظاهرة.
- لا يوجد نص مخترع خارج البيانات المعتمدة.
- الصور المرخصة فقط تظهر كصور إنتاجية.
- المقارنة تعمل كما هي.
- عرض التفاصيل يعمل لكل تخصص.
- لا توجد صورة watermarked في الواجهة.
- الهاتف والكمبيوتر واضحان ومتجاوبان.
- Laravel tests + Vite build ينجحان.
