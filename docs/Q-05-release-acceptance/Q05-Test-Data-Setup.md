## 4. حالات الحافة (Edge Cases) التي يجب تجهيزها يدوياً قبل التنفيذ

### EDGE-01 — جلسة معلقة للطالب أ
**الخطوات:** بعد تشغيل الخادم، سجِّل دخول `student.a`، ابدأ التقييم، أجب عن 5–8 أسئلة،
ثم اخرج دون إكمال.

**النتيجة المتوقعة:** جلسة بحالة in-progress و 5–8 إجابات محفوظة.
**تُستخدم في:** STU-05 (Resume) و ADM-08 (استقرار الجلسة عند النشر الجديد).

### EDGE-02 — نتيجة سابقة للطالب أ (لتجربة Result History)
**الخطوات:** أكمل تقييماً كاملاً بالطالب أ (18 سؤالاً) للحصول على نتيجة منشورة.
**النتيجة المتوقعة:** Result + scores + recommendations.
**تُستخدم في:** STU-10 و STU-11 (Historical Result).

### EDGE-03 — نتيجة للطالب ب لاختبار IDOR العكسي
**الخطوات:** أكمل تقييماً بالطالب ب.
**النتيجة المتوقعة:** Result خاص بالطالب ب.
**تُستخدم في:** S3 و S4 — الطالب أ يحاول فتح نتيجة/جلسة الطالب ب ويرى 403.

## 5. خطوات تجهيز البيئة (للتشغيل لاحقاً)

```bash
# 1. ضبط PATH (Laragon)
export PATH="/d/Application/Laragon/Laragon_Instu/bin/php/php-8.3.30-Win32-vs16-x64:$PATH"

# 2. التأكد من الهجرة والـ Seed
php artisan migrate:fresh --seed   # عند الحاجة لإعادة الضبط

# 3. تشغيل الخادم
php artisan serve                  # http://127.0.0.1:8000
```

> `migrate:fresh --seed` **يمسح** الحسابات. لا يُشغَّل إلا لإعادة الضبط الكامل، ثم
> يُعاد إنشاء الحسابات الثلاثة من هذا الملف.
