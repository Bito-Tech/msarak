# صور دليل التخصصات

ضع الأصول النهائية هنا بالأسماء المحددة في:
`resources/data/specialization-visuals.json`

الصور غير المرخصة لا تُضاف إلى هذا المجلد.

حالة الحزمة الحالية:
- جاهزة المصدر: علوم الحاسوب، الطب، الهندسة المدنية، الهندسة المعمارية، إدارة الأعمال، التصميم الجرافيكي.
- تنتظر أصلًا مرخصًا: التمريض، المحاسبة، الحقوق والقانون، اللغة الإنجليزية والترجمة.

عند عدم وجود صورة إنتاجية لتخصص، واجهة الدليل تستخدم أيقونة التخصص الحالية فقط.
