### 4.5 توضيح ADM-05 (قيد المفتاح الخارجي)

حذف سؤال له خيارات مرتبطة يُصدِر خطأ `ON DELETE RESTRICT`. **هذا سلوك قاعدة
بيانات صحيح ومقصود** (يمنع تفكيك البيانات). الحذف يعمل بالترتيب الصحيح
(خيارات → سؤال). واجهة الإدارة (F-05) يجب أن تتعامل مع هذا الترتيب.

### 4.6 استقرار النتائج التاريخية (ADM-08) — النتيجة الحرجة

```text
قبل النشر:  v12=active,  v13=draft
            result 1: R=100.00  I=33.33  A=16.67  + 5 توصيات

بعد النشر:  v12=retired, v13=active
            result 1: R=100.00  I=33.33  A=16.67  + 5 توصيات  ← لم تتغير
```

**النتائج القديمة محصنة تمامًا ضد نشر الإصدارات الجديدة.**
