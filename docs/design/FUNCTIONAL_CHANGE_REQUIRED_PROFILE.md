# FUNCTIONAL_CHANGE_REQUIRED — حالة استئناف التقييم في الحساب

- المشكلة: صفحة الحساب تعرض اسم المستخدم والبريد فقط، ولا تتلقى حالة جلسة تقييم جارية. لا يمكنها أن تعرض زر «متابعة التقييم» أو عدد المواقف المتبقية بناءً على بيانات موثوقة.
- لماذا لا تكفي الواجهة: `ProfileController::show()` لا يمرر `activeSession` أو تقدم الجلسة إلى `profile.show`. صفحة مقدمة التقييم تتحقق بالفعل من وجود جلسة جارية وتعرض الاستئناف.
- العقد المتأثر: `app/Http/Controllers/ProfileController.php`، وعرض `resources/views/profile/show.blade.php`. إضافة بيانات إلى استجابة JSON الحالية تغير عقد API؛ يمكن إبقاؤها كما هي إن اقتصر التغيير على مسار HTML.
- الحد الأدنى المقترح إذا اعتُمد لاحقًا: جلب أحدث جلسة `in_progress` مملوكة للطالب في طلب HTML، وتمرير وجودها إلى Blade لإظهار حالة دقيقة؛ يظل زر المتابعة متجهًا إلى `assessment.intro` أو يستخدم نموذج بدء/استئناف الجلسة الحالي.
- المخاطر: التباس حالة الجلسة مع التقدم أو عرض حالة قديمة؛ يلزم اختبار مستخدم بلا جلسة وبجلسة نشطة وجلسة مكتملة، والتحقق من عدم تغيير عقد JSON أو صلاحيات الاطلاع.

الحل الحالي في الواجهة: رابط محايد إلى مقدمة التقييم؛ هناك يجري التحقق من الجلسة وعرض زر استئنافها عند وجودها. لم يُنفذ التغيير الوظيفي أعلاه.
